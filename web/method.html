Method — how the data becomes the charts

From raw UN SDMX XML to eight outputs

Overview

un_all.xml (UN SDMX) ──► electricity_consumption_1990_2023.csv (TJ)
        │                              │
UN_CL_AREA_codelist.xml ─┐            TWh = OBS_VALUE / 3600
ne_50m geojson ──────────┴─► country_region.csv ─► analysis_country_year.csv
                                                          │
                                              analysis_region_year.csv
                                                          │
                                   eight figures + this dashboard

Intermediate files: un_all.xml, UN_CL_AREA_codelist.xml, electricity_consumption_1990_2023.csv, country_region.csv, natural_earth_index.csv, analysis_country_year.csv, analysis_region_year.csv.

Shared preparation

TWh conversion

Every value is stored in TJ by the UN service (the UNIT label reads HSO but the number is TJ). Convert with:

TWh = OBS_VALUE / 3600
# e.g. China 2022 FEC: 29,518,462 TJ / 3600 = 8,200 TWh

Sector composition

Services_Other is the row-wise sum of three components (missing values skipped). The parent B47_123 is never added:

Services_Other = B48_1232 + B49_1235 + B51_1234  (min_count=1)
# B47_123 is the parent aggregate and MUST NOT be included

Region derivation

Each CL_AREA country has a Parent (subregion); a static table maps subregion to continent because subregions have no parent:

SUBREGION_TO_REGION = {'155':'Europe', '151':'Europe', ..., '053':'Oceania'}
region = SUBREGION_TO_REGION[subregion_of(code)]

ISO / map link

Natural Earth polygons expose UN_A3 (the UN numeric code); the map is coloured by matching REF_AREA to UN_A3:

fig = px.choropleth(d, geojson=geojson, locations='map_code',
                    featureidkey='properties.UN_A3', ...)

Output 1 — Global trend

Input

analysis_country_year.csv: code, area, year, FEC.

Transformation

Group by year and sum FEC (all reporting); build the fixed sample as the codes present in 1990 and sum FEC for those codes per year.

Code

world = df.groupby('year')['FEC'].sum()
fixed = set(df[df.year == 1990]['code'])
fixed_s = df[df.code.isin(fixed)].groupby('year')['FEC'].sum()
fig = px.line(...)  # two series

Chart specification

Line chart, x=year, y=FEC (TWh), two series (all reporting vs fixed sample). Caption must disclose the ex-Soviet 1990-91 coverage effect.

Output 2 — Top 10 consumers

Input

analysis_country_year.csv filtered to year == 2022.

Transformation

Take the 10 largest FEC values with nlargest(10), sort ascending, plot as a horizontal bar.

Code

d = df[df.year == 2022].nlargest(10, 'FEC').sort_values('FEC')
fig = px.bar(d, x='FEC', y='area', orientation='h')

Chart specification

Horizontal bar, x=FEC (TWh), y=country, ranked.

Output 3 — Regional trends

Input

analysis_region_year.csv (region, year, FEC), excluding World.

Transformation

Filter out the World row and plot one line per region.

Code

d = reg[reg.region != 'World']
fig = px.line(d, x='year', y='FEC', color='region')

Chart specification

Multi-line chart, x=year, y=FEC (TWh), one line per continent.

Output 4 — Sector structure

Input

analysis_country_year.csv, years 1990 and 2022, sector columns.

Transformation

Sum the four sector columns across all countries for each year, normalise to 100%, stack by sector.

Code

totals = d[['Industry','Transport','Residential','Services_Other']].sum()
share = totals / totals.sum() * 100
fig = px.bar(..., barmode='stack')

Chart specification

100% stacked bar, two bars (1990, 2022), stacked by sector. Caption discloses the 21 (1990) / 15 (2022) areas missing an industry row.

Output 5 — Country share change

Input

analysis_country_year.csv, fixed sample, years 1990 and 2022.

Transformation

For each fixed-sample country compute share = FEC / world FEC in each year, then draw a line from the 1990 share to the 2022 share.

Code

share = d.FEC / d.groupby('year').FEC.transform('sum') * 100
fig = go.Figure(); ...  # slope lines per country

Chart specification

Slope chart, x in {1990, 2022}, y = share (%), one line per country, same fixed sample as denominator in both years.

Output 6 — World map, 1990

Input

analysis_country_year.csv (year == 1990) + Natural Earth ne_50m geojson.

Transformation

Resolve combined codes (251→250, 382→380, 579→578, 757→756) to the main country, take log10(FEC), and colour by the UN_A3 link.

Code

d['map_code'] = d.code.map({'251':'250','382':'380','579':'578','757':'756'}).fillna(d.code)
fig = px.choropleth(d, geojson=geojson, locations='map_code',
                    featureidkey='properties.UN_A3', color='FEC_log',
                    color_continuous_scale='Viridis', range_color=[-1, 4])

Chart specification

Choropleth (Natural Earth 50m, UN_A3 link, 214/218 areas coloured). Uses the Viridis scale with range_color=[-1, 4] (log10 TWh).

Output 7 — World map, 2022

Input

analysis_country_year.csv (year == 2022) + Natural Earth ne_50m geojson.

Transformation

Identical to Output 6 but for 2022, so both years share the same colour scale and range_color for a fair visual comparison. A separate animation_frame slider (output_6_7_slider.html) plays 1990-2022.

Code

fig = make_map_figure(2022, df)  # same scale and range_color as 1990

Chart specification

Choropleth (Natural Earth 50m, UN_A3 link). Shares the Viridis scale and range_color=[-1, 4] with Output 6.

Output 8 — Generation mix

Input

OWID electricity-prod-source-stacked.csv, Entity == 'World'.

Transformation

Sum the nine source columns for 2000 and 2022, normalise to 100%, stack by source.

Code

w = world[world.Year == yr][srcs].sum()
fig = px.bar(..., barmode='stack')

Chart specification

100% stacked bar, 2000 vs 2022, stacked by generation source. Caption states this is generation, not consumption, shown only as background.

Validation trace

  • Sector sum == FEC within 1%: 6932/6932 rows (100%).
  • OWID 2022 ratio (UN FEC / OWID demand): China 0.928, Germany 0.884, Japan 0.867, Korea 0.870, Indonesia 0.880 (all in the 0.85-0.95 band); India 0.778 is flagged (high losses / incomplete agriculture reporting).
  • Duplicate count: codes 250/380/578/756 are absent; 840 (US) and 076 (Brazil) present.
  • Top-30 countries account for 88.6% of 2022 world FEC.
  • If any of these changed materially, the chart captions and the limitations section of DATA_PIPELINE.md would have to be revisited.
